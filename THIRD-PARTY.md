# Third-party components

The MIT license covers micro-harness-manager's original code. Dependencies retain their
own licenses; their license texts and notices are kept under `licenses/`.

## Runtime dependencies (in the shipped jar)

| Component | Version | License | Purpose |
|---|---|---|---|
| FlatLaf | 3.6 | Apache-2.0 | Swing look and feel |
| Jackson databind, core, annotations and JSR-310 | 2.18.2 | Apache-2.0 with retained parser notices | JSON and date/time serialization |
| SLF4J API and simple provider | 2.0.17 | MIT | logging |

The installers and portable archives also bundle a trimmed Java runtime (Azul Zulu
OpenJDK, GPL-2.0 with the Classpath Exception). Its legal files ship inside the package
and in each release's `-licenses.zip`.

JUnit Jupiter 5.11.4 is test-only (EPL-2.0) and is not included in the application.

## Code derived from other projects

- `mux` is a fork of jmux ([ghosthack/pseudo-terminal-session-service](https://github.com/ghosthack/pseudo-terminal-session-service), MIT),
  and `app` is ported from Harness Manager ([ghosthack/harness-mgr](https://github.com/ghosthack/harness-mgr), MIT);
  both by the same author.
- `vt`'s character width table (`WidthTable.java`) is generated by
  `vt/scripts/gen_width_table.py` from the Unicode Character Database 17.0.0
  (`EastAsianWidth.txt`, `emoji-data.txt`, `DerivedGeneralCategory.txt`), © Unicode, Inc.,
  under the [Unicode License v3](https://www.unicode.org/license.txt).
- The golden files under `vt/src/test/resources/golden` record this project's own
  emulator; they were checked against JediTerm (Apache-2.0) while it was a test
  dependency, and contain no JediTerm code.
